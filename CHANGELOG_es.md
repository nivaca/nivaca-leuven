# Registro de cambios

Los cambios notables de nivaca-leuven-theme. El código está en
[GitHub](https://github.com/nivaca/nivaca-leuven). El proyecto no tiene
etiquetas de versión ni versiones publicadas, así que las entradas llevan
fecha.

## 2026-08-30

- El README explica cómo instalar el tema con straight.el, desde el
  repositorio de git, en lugar de la receta anterior de `use-package`
  para una copia local.

## 2026-08-28

- Tres capturas de pantalla del tema (`img/`), que se muestran en el
  README.

## 2026-08-27

- Primera versión: `nivaca-leuven-theme.el`, un tema de colores para
  Emacs basado en el tema Leuven de Fabrice Niessen, con las mismas caras
  y las mismas relaciones entre colores, pero con colores un poco más
  oscuros, para un fondo claro más suave. Necesita Emacs 24 o posterior.
- La GNU GPL, versión 3 o posterior (`LICENSE`), heredada de Leuven, y el
  reconocimiento a Fabrice Niessen en el comentario del archivo.
- Un README con la instalación, el uso, algunas soluciones a problemas y
  los créditos.
