# Changelog

All notable changes to nivaca-leuven-theme. The code is on
[GitHub](https://github.com/nivaca/nivaca-leuven). The project has no
version tags or releases, so the entries are dated.

## 2026-08-30

- The README explains how to install the theme with straight.el, from
  the git repository, in place of the earlier `use-package` recipe for a
  local copy.

## 2026-08-28

- Three screenshots of the theme (`img/`), shown in the README.

## 2026-08-27

- First version: `nivaca-leuven-theme.el`, an Emacs colour theme based
  on Fabrice Niessen's Leuven theme, with the same faces and colour
  relationships but with colours a little darker, for a softer light
  background. It needs Emacs 24 or later.
- The GNU GPL, version 3 or later (`LICENSE`), inherited from Leuven, and
  the attribution to Fabrice Niessen in the file's commentary.
- A README with the installation, the use, some troubleshooting and the
  credits.
